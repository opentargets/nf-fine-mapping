# Context

Abstract for the multi-ancestry fine-mapping pipeline


## Writing convensions 
Tense: past tense for what the field/study has done; present tense for field-level claims
Verbs: assertive — "demonstrates", "establishes", "reveals"; never "suggests", "indicates", "appears to"
No: "novel", "groundbreaking", "optimised", self-promotional language
Introduction rule: final sentence of Para 3 states the objective only — no findings
Inline citations in .md drafts: parenthetical author-year format (e.g., Minikel et al., 2024)
Inline citations in .tex: numbered superscript via natbib super option (e.g., \cite{minikel2024} renders as a superscript number)
Do not insert new references without confirming with the user first
